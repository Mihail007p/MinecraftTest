# Автотесты MinecraftTest

Инфраструктура headless-тестирования игры: браузер Chromium (SwiftShader, software WebGL)
управляется скриптами, которые симулируют управление игрой (тач-джойстик, взгляд, кнопки)
и проверяют состояние мира. Скриншоты каждого шага сохраняются в `report/`.

## Состав

| Файл | Что делает |
|---|---|
| `game-test.js` | Полный сценарий: спавн, FPS, взгляд, ходьба, прыжок, добыча блока, установка блока, инвентарь, день/ночь, ошибки, портрет/альбом телефона. Отчёт: `report/report.json` + скриншоты `01-*.png … 11-*.png` |
| `shot.js` | Быстрая проверка: загрузка, WebGL-рендерер, консоль, скриншот `shots/game.png` |
| `debug-move.js` | Прицельная отладка движения и прыжка (позиция/скорость игрока по кадрам) |
| `debug-mine.js` | Прицельная отладка добычи блоков (raycast, mining, дропы) |
| `vision.py` | «Зрение» агента: анализ скриншота (палитра, регионы, diff двух кадров). Требует Pillow |

## Установка

```bash
cd tests
npm install puppeteer-core @sparticuz/chromium   # ~70 МБ, ставится из npm
pip3 install pillow
```

На системах с полным окружением хром запускается как есть. В минимальной песочнице
(нет NSS/NSPR-библиотек) собранные библиотеки кладутся в отдельную папку и передаются
через переменную окружения:

```bash
CHROM_LIBS=/путь/к/библиотекам:/tmp node game-test.js
```

(в этой песочнице: `CHROM_LIBS=/home/user/chromlibs:/tmp`, библиотеки собраны из исходников
`mozilla/nspr` + `melon-gg/libnss3.so`, SwiftShader распакован из пакета `@sparticuz/chromium`).

## Запуск

```bash
cd tests
python3 -m http.server 8080 &          # или любой другой статический сервер для игры
CHROM_LIBS=/home/user/chromlibs:/tmp node game-test.js   # URL=http://127.0.0.1:8080/
```

Переменные: `URL` (адрес игры), `W`/`H` (окно), `OUT` (папка отчёта).

Выходной код: 0 — всё прошло, 2 — есть проваленные шаги или JS-ошибки, 3 — сбой теста.

## Особенности песочницы

- Игра рендерится в software-режиме (SwiftShader), FPS ~8 — это норма для песочницы,
  на реальном GPU будет 30–60.
- В игре dt клампится 50 мс (`Math.min((currentTime-lastTime)/1000, 0.05)`), поэтому при
  низком FPS песочницы игровое время течёт медленнее реального. Тест учитывает это
  (адаптивное ожидание завершения добычи). На устройстве при 30+ fps эффекта нет.
