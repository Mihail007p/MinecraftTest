# MinecraftTest

Мобильная веб-версия Minecraft-подобной песочницы (один файл `index.html`, Three.js внутри).

## Запуск в браузере (без скачивания)

Ветка `arena/01a0432c-minecrafttest` (всегда последняя версия):

https://raw.githack.com/Mihail007p/MinecraftTest/arena/01a0432c-minecrafttest/index.html

Фиксированная версия (коммит `5a5c6b3`, кэш CDN, грузится быстрее):

https://rawcdn.githack.com/Mihail007p/MinecraftTest/5a5c6b3e457d484178af2a7eb21a30a08ecb37e3/index.html

Ветка `main`:

https://raw.githack.com/Mihail007p/MinecraftTest/main/index.html

> При первом открытии githack показывает страницу-предупреждение — нажми «Open the page».

## Локально

```bash
python3 -m http.server 8080
# открыть http://localhost:8080/index.html
```
